# Source artwork

Drop the original logo artwork here.

Preferred, in order:

1. **SVG** — recolouring is exact and lossless; the shapes are untouched.
2. **PNG at the highest resolution available** — a small export limits how clean
   the black-and-white conversion and any vector trace can be.

Generated marks live one level up in `brand/`. Nothing in this folder is
generated — it is the input, kept so the derived assets can always be rebuilt.
